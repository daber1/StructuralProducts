# Подключение вычислительного модуля в другой работе

Требуется Python 3.11+. Имя устанавливаемого пакета — `structural-products`,
имя для импорта в Python — `structpy`.

## Установка

В окружении другого проекта выполните:

```shell
python -m pip install "structural-products @ git+https://github.com/daber1/StructuralProducts.git"
```

Для этой команды нужен Git. Если Git не установлен, скачайте исходники
репозитория, распакуйте их и выполните `python -m pip install /path/to/StructuralProducts`.
Путь замените на расположение распакованного проекта.

Для воспроизводимой работы фиксируйте полный SHA коммита в зависимостях:

```text
structural-products @ git+https://github.com/daber1/StructuralProducts.git@<COMMIT_SHA>
```

Замените `<COMMIT_SHA>` на SHA выбранного коммита. Сохраните также версии
зависимостей окружения, входные параметры и seed. Разные версии NumPy могут
давать отличия в численных результатах.

Базовая установка включает NumPy, pandas и requests. Для исторического
скрипта и графиков установите `".[research]"` из каталога репозитория;
для разработки и всех тестов — `".[dev]"`.

## Самостоятельный пример

Скопируйте `examples/reuse_pricer.py` в другую работу и запустите:

```shell
python reuse_pricer.py
```

Пример использует только установленный `structpy`, явно заданные рыночные
параметры и стандартную библиотеку. Он не читает файлы репозитория и не требует
интернета или `.env`. Результат — JSON с fair value, Monte Carlo standard error,
95%-м доверительным интервалом и риск-метриками.

## Основные классы

| Задача | Импорт и метод |
| --- | --- |
| Создать продукт из словаря | `from structpy.parser import parse_dict_config` |
| Создать продукт из JSON-строки | `from structpy.parser import load_product` |
| Сгенерировать траектории | `from structpy.core.scenario import ScenarioGenerator` |
| Оценить стоимость | `from structpy.core.pricer import Pricer`, метод `price` |
| Рассчитать риск и дельту | `from structpy.core.risk import RiskManager`, методы `calculate_metrics` и `calculate_delta` |

Готовые конфигурации находятся в `examples/market_structured_notes.json`.
Это список словарей: в каждом `product` содержит конфигурацию продукта,
а `market_params` — рыночные параметры и настройки симуляции.
Файл с примерами и скрипты запуска доступны в исходниках; в установленный
пакет входят только модули `structpy`.

## Соглашения о входных данных

- `nominal` и цены задаются в денежных единицах. Валюта — информационное поле,
  автоматической конвертации валют нет.
- `coupon_rate` — годовая ставка в долях единицы: `0.12` означает 12% годовых.
  Выплата на одной дате наблюдения равна `nominal * coupon_rate / coupon_frequency`
  до применения memory effect.
- Волатильности, безрисковая ставка и дивидендные доходности также задаются
  в годовых долях единицы. Дисконтирование — `exp(-r * t)`.
- Барьеры и `strike` — отношения к стартовой цене: `0.7` означает 70%.
- `T` — срок симуляции в годах; `n_steps` — число равномерных дат наблюдения.
  Для годового продукта с квартальными купонами используйте `T=1`, `n_steps=4`,
  `coupon_frequency=4`. Каждый шаг проверяет купон и autocall; увеличение
  числа шагов меняет условия наблюдения продукта.
- Порядок строк и столбцов корреляционной матрицы должен соответствовать
  порядку `tickers`. Матрица должна допускать разложение Холецкого.
- `product.set_initial_prices(...)` задаёт фиксинги для расчёта барьеров.
  `ScenarioGenerator.initial_prices` задаёт цены, с которых начинаются
  траектории. При оценке на дату выпуска эти значения совпадают.
- Барьер защиты капитала проверяется на последней дате наблюдения;
  непрерывного контроля барьера внутри интервалов нет.
- Передавайте одинаковые `T`, `n_steps`, `n_scenarios` и `seed` при сравнении
  стоимости и риск-метрик. Для дельты с собственным горизонтом вызывайте
  `calculate_delta(ticker, T=..., n_steps=..., n_scenarios=..., seed=...)`:
  `calculate_all_deltas` использует горизонт и число шагов по умолчанию.

## Интерпретация результата

`fair_value` — средняя дисконтированная сумма выплат. `std_error` и
`confidence_interval_95` характеризуют погрешность Monte Carlo при заданных
параметрах модели, а не неопределённость самой модели или рыночных параметров.

`mean_payout_undiscounted` — средняя сумма выплат без дисконтирования.
`payouts` содержит суммы выплат по сценариям только при `n_scenarios <= 1000`;
для большего числа сценариев возвращается пустой список.

`RiskManager.calculate_metrics` считает убытки как номинал минус полная
недисконтированная выплата до погашения или autocall. `VaR` и
`Expected_Shortfall` ограничены снизу нулём. Это метрики по траекториям
используемой риск-нейтральной модели, а не регуляторный VaR на заданном
краткосрочном горизонте по физической мере.

Модель учебная: она не учитывает кредитный риск эмитента, ликвидность,
комиссии и полную поверхность волатильности. Ограничения подробно перечислены
в README. При использовании в исследовании укажите репозиторий, коммит,
исходные параметры и принятые допущения.
