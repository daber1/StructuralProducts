# Ценообразование структурных облигаций

Учебный проект, цель которого — сформировать воспроизводимую модель оценки структурных облигаций. Модель рассчитывает справедливую стоимость продукта, базовые риск-метрики `VaR`/`ES` и позволяет проверять поведение payoff-структур на рыночных данных.

Проект покрывает следующие задачи:

- описание пошаговой Monte Carlo методологии оценки структурных продуктов;
- агрегация рыночной информации через провайдеры данных и исторический пример на данных FRED;
- моделирование динамики базовых активов через GBM и дополнительную модель Merton Jump Diffusion;
- задание корреляции, волатильности, ставки и дивидендной доходности;
- реализация сложной логики выплат: купоны, memory effect, autocall, барьер защиты капитала, участие в росте, `worst_of` и `average` корзины;
- расчет справедливой стоимости, standard error, `VaR`, `ES`, max loss и дельт.

Проект является учебной реализацией: параметры волатильности, ставок и корреляций задаются явно или берутся как рыночные прокси, а не калибруются к полной опционной поверхности.

## Что реализовано

- `PhoenixAutocallProduct` — универсальный класс продукта с купонами, memory effect, autocall, защитой капитала, участием в росте и несколькими способами агрегации корзины.
- `ScenarioGenerator` — генерация риск-нейтральных траекторий базовых активов в модели GBM с учетом волатильности, ставки, дивидендной доходности и корреляционной матрицы.
- `Pricer` — Monte Carlo расчет fair value, standard error и средней выплаты без дисконтирования.
- `RiskManager` — расчет `VaR`, `Expected Shortfall`, максимального убытка и дельт.
- `MarketDataProvider` — интерфейс для агрегации рыночных данных; в проекте есть mock-провайдер и провайдер MOEX.
- `MertonJumpDiffusion` — дополнительная модель динамики базового актива с простой калибровкой по историческим доходностям.
- Историческая учебная переоценка продукта на S&P 500 с использованием данных FRED (`SP500`, `DGS3MO`, `VIXCLS`).

## Запуск тестов

```powershell
python -m pytest -q
```

Тесты проверяют:

- корректность payoff-логики продукта;
- приближенное совпадение с аналитическими предельными случаями;
- чувствительность basket-продуктов к корреляции;
- ручные сценарии для разных структур продуктов;
- расчет риск-метрик `VaR`/`ES` и дельт;
- работу провайдеров рыночных данных;
- калибровку и симуляцию модели Merton Jump Diffusion;
- историческую daily schedule логику для S&P 500 backtest.

## Пример прайсинга

```powershell
python price_products.py
```

Скрипт рассчитывает autocall-продукт, печатает ключевые метрики и сохраняет результат в `pricing_report.json`.

В результате выводятся:

- fair value;
- standard error;
- средняя выплата без дисконтирования;
- `VaR 95%`, `ES` и максимальный убыток;
- дельты по базовым активам.

## Историческая переоценка S&P 500 продукта

```powershell
python historical_repricing_sp500_barrier.py
```

Скрипт загружает из FRED дневные данные:

- `SP500` — уровень базового актива;
- `DGS3MO` — прокси краткосрочной безрисковой ставки USD;
- `VIXCLS` — прокси ожидаемой волатильности S&P 500.

На каждой торговой дате пересчитывается модельная стоимость учебного продукта с участием в росте и барьером защиты капитала 70%.

Результаты сохраняются в:

```text
artifacts/sp500_accelerated_barrier_note_backtest.csv
artifacts/sp500_accelerated_barrier_note_backtest.png
```

## Ограничения модели

Модель является учебной и не претендует на точную дилерскую оценку реального структурного продукта. В частности:

- используется GBM с постоянной волатильностью внутри одного прогона;
- Merton Jump Diffusion реализован как дополнительная модель, но основной pricer отчета использует GBM;
- не моделируется стохастическая волатильность и полноценная volatility surface;
- не выполняется промышленная калибровка к опционной поверхности;
- ставка задается одной величиной, а не полной кривой ставок;
- в историческом примере `DGS3MO` и `VIXCLS` используются как приближенные рыночные прокси;
- не учитываются ликвидность, bid-ask spread, комиссии, кредитный риск эмитента и издержки хеджирования.
